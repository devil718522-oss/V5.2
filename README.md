## 驗證原則
歷史訊號只使用訊號當日以前可知的價格、成交量與 0050 市場狀態。V5.1 的當期基本面/籌碼品質分不回填到歷史，以免產生偷看未來偏誤。訊號於當日收盤後成立，次一交易日收盤作為一致的驗證進場基準。

研究用途，不構成投資建議。
